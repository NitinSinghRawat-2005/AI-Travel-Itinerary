# AI Travel Itinerary Generator

An AI-powered travel itinerary generator that creates personalized day-by-day travel plans based on destination, number of days, interests, budget, and travel pace.

## 🚀 Live Demo

[**Open the Live Website →**](https://t4-ashen.vercel.app)

## 💻 GitHub Repository

This repository contains the complete source code for the project.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Gemini API
- Vercel Serverless Functions

## ✨ Features

- Generate AI-powered travel itineraries
- Select destination and number of days
- Specify interests
- Choose budget and travel pace
- Generate a structured day-by-day itinerary
- Server-side API handling using Vercel
